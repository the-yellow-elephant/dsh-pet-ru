# UPDATE.md — как обновить русский патч под новую версию dsh-pet

Инструкция для агента. Патч собран и проверен на **dsh-pet 0.4.7**. Когда плагин
обновится, строки в бандлах изменятся, и часть блоков в `data/*.json` перестанет
совпадать. Ниже — порядок действий, чтобы найти новое и дособрать патч.

## 0. Что понадобится

- Node.js 22+ (есть в DSH).
- git (для диффов).
- Доступ к npm-реестру (скачать чистый тарбол нужной версии).
- Установленный dsh-pet в `~/.dsh/profiles/<profile>/node_modules/dsh-pet`.

## 1. Узнать версию

```powershell
(Get-Content "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-pet\package.json" -Raw | ConvertFrom-Json).version
```

Если версия **0.4.7** — обновление не нужно, ставьте как обычно (`node apply.mjs`).

## 2. Скачать чистую версию

```powershell
$v = "0.4.2"   # подставить фактическую
$w = "D:\DSH\Main\.tmp-dsh-pet-$v"
New-Item -ItemType Directory -Force $w | Out-Null
Invoke-WebRequest "https://registry.npmjs.org/dsh-pet/-/dsh-pet-$v.tgz" -OutFile "$w\dsh-pet.tgz" -UseBasicParsing
tar -xzf "$w\dsh-pet.tgz" -C $w
# чистая распаковка: $w\package
```

## 3. Применить текущий патч к чистой копии и увидеть промахи

```powershell
Copy-Item "$w\package" "$w\ru" -Recurse
node apply.mjs --pkg "$w\ru" --dry-run --verbose
```

В конце будет список «не совпало». Это строки, которых больше нет (или они
изменились) в новой версии. Именно их надо перевести заново.

## 4. Найти, что изменилось в интерфейсе

Сравните чистую предыдущую (0.4.7) и чистую новую версии:

```powershell
git diff --no-index -U3 -- "D:\DSH\Main\.tmp-ru-clean\package\lib\client.js" "$w\package\lib\client.js"
```

Так же по остальным файлам из списка в `apply.mjs` (TABLES). Ищите:
- новые китайские или английские строки в меню, чате, туду, балансе, уведомлениях;
- изменённые формулировки (старый блок не совпал → новая строка);
- новые названия анимаций (карта `ANIM_LABELS` / `RU_ANIM`) и мемов (`RU_MEME`).

## 5. Перевести и вписать

Правьте **рабочую копию** `$w\ru` (не установленный плагин):

- меню/анимации/категории — `lib/client.js`, `runtime/electron-helper/shared-core.js`;
- чат — `lib/chat-panel.js`;
- хост-пузыри и промпты — `lib/index.js`;
- десктоп — `runtime/electron-helper/*` и `sprite/*`.

Глоссарий, чтобы стиль не разъезжался:

| Понятие | Как писать |
|---|---|
| обращение | **шеф**; в подколах — **вайбкодер** |
| питомец о себе | **рыбка** (не «китиха») |
| статусы | «Думаю, что дальше…», «Уже работаю», «Этот шаг готов, смотрим дальше» |
| сон | «Я сплю, не трогай…», «Выспалась, шеф!» |
| баланс | «Баланс (час пик / по скидке)», «Провайдер: …» |
| туду | «Задачи», «Добавить», «Без срока», «Просрочено на…» |
| чат | «Напишите что-нибудь…», «Озвучить», «Граница памяти» |

Новые названия анимаций/мемов добавляйте в соответствующие карты
(`RU_ANIM`/`RU_MEME` в двух файлах) и в `data/memes-ru.json`, если менялись файлы мемов.

## 6. Пересобрать таблицы

```powershell
node tools/gen_tables.mjs --clean "$w\package" --patched "$w\ru" --out data
```

Скрипт перезапишет `data/*.json` парами «до/после» для всех 10 файлов.

Проверьте, что в выводе нет предупреждений «не уникальный блок»: если есть —
увеличьте контекст в `tools/gen_tables.mjs` (флаг `-U3` → `-U4`) или поправьте
соответствующую строку вручную.

## 7. Обновить версию и проверить

- В `apply.mjs` поменяйте `const TESTED_VERSION = '0.4.7'` на новую.
- Прогоните на свежей копии:

```powershell
Copy-Item "$w\package" "$w\test" -Recurse
node apply.mjs --pkg "$w\test"
node apply.mjs --pkg "$w\test"      # повторно: должно быть «0 файлов»
```

- `node --check` всех изменённых `.js` (apply.mjs делает это сам).
- Проверьте установку на живом профиле и перезапустите DSH.

## 8. Мемы, шрифт, конфиг

- Новые мемы: положите PNG 384×384 в `assets/memes-ru/` под исходными именами и
  допишите пары в `data/memes-ru.json`.
- Если пропали старые мемы — уберите их из `data/memes-ru.json`.
- Шрифт и конфиг обычно не меняются; если в конфиге появились новые ключи —
  добавьте их в `config/main-config.ru.jsonc`.

## 9. Коммит

```powershell
git add -A
git commit -m "update: dsh-pet <версия>"
```

В сообщении укажите, что именно переведено и что осталось (если осталось).
