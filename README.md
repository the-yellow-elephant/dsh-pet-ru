# dsh-pet-ru 🐾🇷🇺

Русская локализация плагина **[dsh-pet](https://github.com/PC2005-cloud/dsh-pet)** для DeepSeek Harness.

Плагин изначально китайский: меню, названия анимаций, чат, туду, баланс и подписи
инструментов зашиты в бандлы. Этот патч заменяет их на русские, ставит русские
мемы (24 картинки), шрифт **Nunito** с кириллицей и русскую персону питомца.

> **Сначала нужен сам dsh-pet.** Это отдельный плагин, без него патч ставить некуда.
> Установить его можно через маркет плагинов DSH — раздел **Discover** — или командой
> `dsh plugin --profile desktop add dsh-pet`. Инструкция в его репозитории:
> **[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)**.
> Этот репозиторий — только русская локализация поверх него.

**Проверено на:** dsh-pet **0.4.7** / DSH desktop (Windows 11).

## Что становится русским

| Слой | Примеры |
|---|---|
| Меню | «Открыть приложение», «Баланс», «Задачи», «Болтовня», «Чат», «Спать», «Действия», «Положение», «Ещё», «На исходную» |
| Анимации (109) | «Дышит», «Кубик Рубика», «Ест рис», «Сон: засыпает» … (имена файлов не меняются) |
| Мемы | 24 перерисованных картинки + русские названия в меню |
| Чат | «Напишите что-нибудь…», «Озвучить», «Граница памяти», подтверждения удаления |
| Задачи | «Задачи», «Добавить», «Сегодня/Завтра», «Без срока», «Просрочено на…» |
| Баланс | «Баланс (час пик / по скидке) $…», «Провайдер: …» |
| Уведомления | «Разговор завершён», «Ошибка генерации», «Запрос разрешения» |
| Хост-слой | подписи инструментов («{cmd} запущен», «{target} — уже пишу»), напоминания, сообщения Electron, промпты модели |
| Шрифт | Nunito вместо китайского «软糖体» (кириллица) |
| Конфиг | персона «рыбка-служанка», «шеф» / «вайбкодер» к месту, сердечки, русские описания мемов |

Страница настроек принудительно на русском: плагин отдаёт её из русского
словаря независимо от языка DSH. Вкладка называется **«Маскот»**. Голоса: четыре
китайских (помечены «китайский») и два русских — **Светлана** и **Дмитрий**.

## Установка

```sh
# 1. сам плагин (если ещё не стоит)
#    вариант А: в DSH откройте Discover (маркет плагинов) → найдите dsh-pet → Установить
#    вариант Б: командой
dsh plugin --profile desktop add dsh-pet

# 2. патч
git clone https://github.com/the-yellow-elephant/dsh-pet-ru.git
cd dsh-pet-ru
node apply.mjs --profile desktop --install-config

# 3. перезапустить DSH
```

`--install-config` копирует русскую персону/статусы/описания мемов в
`~/.dsh/dsh-pet/main-config.jsonc` (если файла нет).

## Установка агентом

Скопируйте это сообщение и отправьте своему агенту в DSH (подставьте URL репозитория):

```text
Возьми репозиторий dsh-pet-ru: https://github.com/the-yellow-elephant/dsh-pet-ru.
Установи русский патч плагина dsh-pet:
1) склонируй репозиторий в D:\DSH\dsh-pet-ru (если уже есть — обнови git pull);
2) проверь установленную версию dsh-pet (package.json в профиле desktop);
3) если версия 0.4.7 — запусти: node apply.mjs --profile desktop --install-config;
4) если версия новее — сначала прочитай UPDATE.md в репозитории и обнови таблицы, потом ставь;
5) перезапусти DSH и проверь: меню на русском, чат, задачи, баланс, мемы.
```

## Если версия dsh-pet новее

Патч собран под **0.4.7**. Когда плагин обновится, часть строк перестанет совпадать.
В репозитории есть инструкция для агента: **[UPDATE.md](UPDATE.md)** — что проверить,
как найти новые строки, перевести их и пересобрать таблицы.

Короткое сообщение агенту:

```text
dsh-pet обновился до версии <ВЕРСИЯ>.
Прочитай инструкцию https://github.com/the-yellow-elephant/dsh-pet-ru/UPDATE.md и обнови русскую локализацию:
проверь, что нового появилось и что осталось перевести, пересобери data/*.json
через tools/gen_tables.mjs, проверь патч на чистой копии и закоммить изменения.
```

### Опции

| Опция | Смысл |
|---|---|
| `--profile <name>` | целевой профиль (по умолчанию все, где найден dsh-pet) |
| `--pkg <dir>` | указать каталог плагина напрямую |
| `--dry-run` | показать, что будет изменено, ничего не писать |
| `--install-config` | скопировать русский конфиг, если его ещё нет |
| `--verbose` | показать все несовпавшие строки |

## Обновление и откат

Патч правит `node_modules` напрямую. После обновления/переустановки dsh-pet
он слетает — просто запустите `node apply.mjs` снова (идемпотентно).

Откат:

```sh
dsh plugin --profile desktop remove dsh-pet
dsh plugin --profile desktop add dsh-pet --save-exact
```

или удалить `~/.dsh/dsh-pet/main-config.jsonc`, если добавляли русскую персону.

## Что доработано и переведено

### Перевод

- **Меню** — верхние пункты, подменю «Картинки», «Действия», «Положение», «Ещё»,
  подписи «Спать/Разбудить», «На исходную», «Перезагрузить настройки»;
- **109 названий анимаций** и 5 категорий — по-русски в меню, файлы не переименованы;
- **27 мемов** — русские названия в меню и русские описания для модели
  (именно по описанию она выбирает картинку и строит фразу);
- **чат** — placeholder, кнопки, подтверждения удаления, «Граница памяти»,
  «Озвучить», даты, «Это всё (максимум N шагов)»;
- **задачи** — панель, календарь, «Сегодня/Завтра/Послезавтра», «Без срока»,
  «Просрочено на…», «Осталось…»;
- **баланс** — «Баланс (час пик / по скидке)», «Провайдер: …», суммы, «Сброшено»;
- **уведомления** — «Разговор завершён», «Ошибка генерации», «Ответ обрезан»,
  «Достигнут лимит токенов», «Запрос разрешения», «Модель ждёт ответа»;
- **хост-слой** — ~130 подписей инструментов («{cmd} запущен», «{target} — уже
  пишу», git/shell-команды), напоминания о задачах, сообщения Electron
  (загрузка/готовность), промпты для модели;
- **персона** — рыбка-служанка, обращение «шеф», «вайбкодер» только к месту (когда речь о коде),
  сердечки изредка;
- **страница настроек** — принудительно на русском (не зависит от языка DSH),
  вкладка называется «Маскот», голоса подписаны языком.

### Доработки сверх перевода

- **24 мема перерисованы на русском** (текст на картинках, не только подписи),
  оригиналы сохраняются в `assets/memes.zh-backup` при установке;
- **шрифт Nunito** с кириллицей вместо китайского «软糖体», плюс `Segoe UI Emoji`
  для ❤ и эмодзи;
- **размер мема в пузыре** увеличен для читаемости (13×m), при этом картинка
  ограничена шириной пузыря и `max-height:32vh`, чтобы не вылезать за балун
  и не уезжать за край экрана;
- **метки тарифа** DeepSeek (`peak`/`idle`) переведены как «час пик»/«по скидке»,
  а не как «много/мало денег»;
- **описания мемов** переписаны от первого лица там, где это важно: ошибку
  в меме про иероглифы признаёт сама рыбка, а не пользователь;
- **русские голоса TTS** — добавлены `ru-RU-SvetlanaNeural` и `ru-RU-DmitryNeural`,
  китайские помечены как «китайский», русский голос по умолчанию — Светлана;
- **озвучка не читает символы** — `~`, `❤`, `♥`, `♡` вырезаются перед синтезом,
  чтобы не звучало «тильда красное сердце»;
- **патч идемпотентен** и проверяется `node --check` после каждой установки.

### Ограничения

- собрано и проверено под **dsh-pet 0.4.7**; для новой версии — см. [UPDATE.md](UPDATE.md);
- правки живут в `node_modules`, после обновления плагина их нужно накатить заново;
- служебные логи/консольные сообщения не переводятся — они не видны в интерфейсе.

## Как устроено

- `data/*.json` — пары «до/после» (уникальные куски бандлов 0.4.7), включая
  таблицы меню, карту русских названий анимаций и мемов, подписи хоста.
- `apply.mjs` — резолвит профиль, применяет пары, копирует шрифт и мемы,
  проверяет `node --check` каждого изменённого JS.
- `assets/memes-ru/` — 24 готовых PNG (384 px), `data/memes-ru.json` — их
  соответствие исходным именам файлов.
- `assets/fonts/Nunito.ttf` — OFL, лицензия рядом (`OFL.txt`).

Таблицы собраны побайтовым диффом чистой 0.4.7 и проверенной русской сборки;
на чистой копии патч даёт байт-в-байт тот же результат.
