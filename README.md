# dsh-pet-ru 🐾🇷🇺

Русская локализация плагина **[dsh-pet](https://github.com/PC2005-cloud/dsh-pet)** для DeepSeek Harness.

Плагин изначально китайский: меню, названия анимаций, чат, туду, баланс и подписи
инструментов зашиты в бандлы. Этот патч заменяет их на русские, ставит русские
мемы (24 картинки), шрифт **Nunito** с кириллицей и русскую персону питомца.

**Проверено на:** dsh-pet **0.4.1** / DSH desktop (Windows 11).

---

## Что становится русским

| Слой | Примеры |
|---|---|
| Меню | «Открыть приложение», «Баланс», «Задачи», «Болтовня», «Чат», «Спать», «Действия», «Положение», «Ещё», «На исходную» |
| Анимации (109) | «Дышит», «Кубик Рубика», «Ест рис», «Сон: засыпает» … (имена файлов не меняются) |
| Мемы | 24 перерисованных картинки + русские названия в меню |
| Чат | «Напишите что-нибудь…», «Озвучить», «Граница памяти», подтверждения удаления |
| Задачи | «Задачи», «Добавить», «Сегодня/Завтра», «Без срока», «Просрочено на…» |
| Баланс | «Баланс (час пик / по скидке) $…», «Провайдер: …» |
| Уведомления | «Разговор завершён», «Ошибка генерации», «Запрос разрешения» |
| Хост-слой | подписи инструментов («{cmd} запущен», «{target} — уже пишу»), напоминания, сообщения Electron, промпты модели |
| Шрифт | Nunito вместо китайского «软糖体» (кириллица) |
| Конфиг | персона «рыбка-служанка», «шеф»/«вайбкодер», сердечки, русские описания мемов |

Страница настроек плагина не входит в таблицы: dsh-pet сам содержит русский
словарь, поэтому она следует языку DSH (**Settings → General → Language → Русский**
или English — на выбор).

## Установка

```sh
# 1. сам плагин (если ещё не стоит)
dsh plugin --profile desktop add dsh-pet

# 2. патч
git clone <этот репозиторий> dsh-pet-ru
cd dsh-pet-ru
node apply.mjs --profile desktop --install-config

# 3. перезапустить DSH
```

`--install-config` копирует русскую персону/статусы/описания мемов в
`~/.dsh/dsh-pet/main-config.jsonc` (если файла нет).

### Опции

| Опция | Смысл |
|---|---|
| `--profile <name>` | целевой профиль (по умолчанию все, где найден dsh-pet) |
| `--pkg <dir>` | указать каталог плагина напрямую |
| `--dry-run` | показать, что будет изменено, ничего не писать |
| `--install-config` | скопировать русский конфиг, если его ещё нет |
| `--verbose` | показать все несовпавшие строки |

## Обновление и откат

Патч правит `node_modules` напрямую. После обновления/переустановки dsh-pet
он слетает — просто запустите `node apply.mjs` снова (идемпотентно).

Откат:

```sh
dsh plugin --profile desktop remove dsh-pet
dsh plugin --profile desktop add dsh-pet --save-exact
```

или удалить `~/.dsh/dsh-pet/main-config.jsonc`, если добавляли русскую персону.

## Как устроено

- `data/*.json` — пары «до/после» (уникальные куски бандлов 0.4.1), включая
  таблицы меню, карту русских названий анимаций и мемов, подписи хоста.
- `apply.mjs` — резолвит профиль, применяет пары, копирует шрифт и мемы,
  проверяет `node --check` каждого изменённого JS.
- `assets/memes-ru/` — 24 готовых PNG (384 px), `data/memes-ru.json` — их
  соответствие исходным именам файлов.
- `assets/fonts/Nunito.ttf` — OFL, лицензия рядом (`OFL.txt`).

Таблицы собраны побайтовым диффом чистой 0.4.1 и проверенной русской сборки;
на чистой копии патч даёт байт-в-байт тот же результат.
